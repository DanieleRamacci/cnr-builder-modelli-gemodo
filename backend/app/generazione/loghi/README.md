# Loghi della cornice di pagina (012 FR-011)

Qui va il file del logo dell'ente, con questo nome esatto:

- `logo-ente.png` - PNG, preferibilmente con sfondo trasparente e almeno
  600 px di larghezza; nel PDF e' reso alto 14 mm, in alto a sinistra.

Finche' il file manca, la cornice si rende senza logo e la pagina di
configurazione lo dice. Il logo e' identita' istituzionale: lo fornisce
l'ente, non si genera e non si carica dall'interfaccia (`LOGHI` in
`../renderer.py`).
