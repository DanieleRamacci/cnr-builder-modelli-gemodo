Autenticazione manuale

Il flusso operativo GEBAN verso GEMODO è server-to-server: GEBAN ottiene un token tecnico geban-backend da Keycloak e chiama GEMODO. Il login SSO utente umano nella pagina non è ancora parte di questa release; arriverà con il frontend applicativo.
1. Ottieni il token Usa il secret del client tecnico geban-backend nel realm CNR di test.
2. Apri Swagger Vai su /docs/geban-catalog, premi Authorize e incolla il valore di access_token.
3. Esegui le chiamate Prova prima tipi/categorie/modelli, poi campi richiesti e infine validazione payload. 
curl -s -X POST "https://sso.test.si.cnr.it/auth/realms/cnr/protocol/openid-connect/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=geban-backend" \
  -d "client_secret=$GEBAN_CLIENT_SECRET" \
  | jq -r .access_token

In Swagger incolla il token senza salvarlo in questa pagina. Se Swagger chiede il valore Bearer, incolla solo l'access_token; se il client usato richiede l'header completo, usa Authorization: Bearer <token>.
