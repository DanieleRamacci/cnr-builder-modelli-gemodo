Chiamata autenticata

GEBAN deve ottenere un token Keycloak con client tecnico geban-backend, audience gemodo-backend e ruolo client coerente. 

curl -s -X POST "$KEYCLOAK_ISSUER_URL/protocol/openid-connect/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=geban-backend" \
  -d "client_secret=$GEBAN_CLIENT_SECRET"
curl -s "$GEMODO_BASE_URL/api/v1/catalogo/modelli?tipo_documento=BANDO_CONCORSO&categoria=DEMO" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
Il backend GEMODO non conserva il secret di geban-backend: quel secret serve al client GEBAN per ottenere il token. GEMODO valida solo il Bearer token ricevuto.
