Oggi il backend accetta un Bearer token Keycloak del client tecnico geban-backend. Il login SSO utente umano non è ancora implementato nella pagina: per il test incolla qui un access token valido.

Sequenza consigliata: carica categorie, scegli categoria, carica modelli, scegli modello, leggi campi richiesti, valida il payload. Il PDF verrà collegato appena sarà implementata la generazione documentale.

API disponibili ora

GET/api/v1/catalogo/tipi-documento DOCUMENTI_VIEWER

Restituisce i tipi documento disponibili per l'uso operativo.

{
  "items": [
    { "codice": "BANDO_CONCORSO", "descrizione": "Bando di concorso" }
  ]
}
GET/api/v1/catalogo/tipi-documento/{codice}/categorie DOCUMENTI_VIEWER

Restituisce le categorie attive per il tipo documento scelto.

{
  "tipo_documento": "BANDO_CONCORSO",
  "categorie": [
    { "codice": "DEMO", "descrizione": "Categoria demo" }
  ]
}
GET/api/v1/catalogo/modelli DOCUMENTI_VIEWER

Filtra versioni modello pubblicate per tipo documento, categoria e tipologia SOL.

{
  "tipo_documento": "BANDO_CONCORSO",
  "categoria": "DEMO",
  "codice_tipologia": null,
  "modalita": "OPERATIVA",
  "modelli": [
    {
      "modello_id": 1,
      "modello_versione_id": 1,
      "codice": "demo-bando-concorso-standard-v1",
      "descrizione": "demo-bando-concorso-standard-v1",
      "variante": "STANDARD",
      "versione": 1,
      "stato": "PUBBLICATO"
    }
  ]
}
GET/api/v1/catalogo/modelli/{id}/campi-richiesti DOCUMENTI_VIEWER

Restituisce il contratto dati per costruire la maschera GEBAN e validare il payload.

{
  "modello_versione_id": 1,
  "tipo_documento": "BANDO_CONCORSO",
  "categoria": "DEMO",
  "campi": [
    {
      "codice": "codice_bando",
      "etichetta": "Codice bando",
      "tipo": "string",
      "lingua": "IT",
      "obbligatorio": true,
      "ordine": 1
    }
  ],
  "schema": {
    "type": "object",
    "additionalProperties": false
  }
}
POST/api/v1/documenti/valida DOCUMENTI_GENERATORE
